# 创作规划（大纲）

位置：摘要 → 创作规划。模型根据剧情和用户要求生成分阶段规划，也可不填要求一键生成；确认后，每次只将当前阶段注入正文。

## 用法

1. 展开「生成规划草稿」，填写期望的故事走向：人物关系的发展、需要的转折、节奏、不希望出现的情节。选择阶段数（1–12），点击「生成规划草稿」。不想填写时可用「一键生成」，见下节。
2. 模型参考最近的剧情、用户原话、已有的摘要和总结（包括 L1/L2）、人物和物品等状态、角色卡、当前启用的世界书条目和双子札记中已确认的安排生成草稿，详见「生成时参考的资料」。
3. 在草稿中修改规划标题、整体发展方向、整体约束，以及各阶段的目标、剧情要点、发展方式和推进条件，然后点击「保存草稿」。
4. 点击「确认加入计划」。确认前不影响正文；重新生成的草稿也不会替换正在使用的规划。
5. 正常聊天。整体约束和当前阶段注入正文。阶段可手动切换（「下一阶段」「结束规划」），也可在推进条件检查中开启自动切换；可随时暂停。规划确认后，推进条件仍可修改：点当前阶段或「全部阶段」中推进条件旁的编辑键，在弹窗中修改并保存。只改推进条件，阶段进度和其他内容不变；当前阶段已有的检查结果随之作废。

规划是写作方向，不是已发生的事件。切换阶段只表示规划进度，摘要仍只记录正文中实际发生的事。模型不保证每轮都按规划书写；用户最新的要求和已有剧情优先，模型也不会替用户的角色做决定。剧情明显偏离时，可按新的要求重新生成，核对后替换。

## 一键生成

不填写要求、不指定阶段数，由模型根据角色卡、世界书、宝书记忆和最近剧情自行规划后续 3～6 个阶段：延续未了结的计划和悬念，运用世界书中已有的设定、势力和人物关系，节奏由近及远。

- 没有规划和草稿时，「创作规划」中显示「一键生成规划」卡片，点击「一键生成」即可；生成期间可在卡片中取消，并查看正在生成的内容。
- 已有规划或草稿时，在「修改或重新生成规划」中点击阶段数旁的「一键生成」，确认后生成。一键生成不使用上方填写的要求和阶段数；成功后替换当前草稿（包括未保存的修改），正在使用的规划不受影响。
- 结果同样先存为草稿，「当时的要求」一栏注明来自一键生成。生成完成后自动展开草稿编辑器，核对、修改并确认加入计划后才生效。
- 模型给出的阶段数在 1–12 之间均可接受；填写要求时指定的阶段数仍须一致。

## 生成时参考的资料

填写要求的生成和一键生成使用同样的资料：

- 最近 8 条楼层的正文和用户原话（不含插件的提示楼、番外楼和酒馆原生的系统楼；被宝书隐藏的旧楼照常计入），共约 24000 字。
- 已有的 L1/L2 总结和当前状态（主角、人物、物品、场景、计划等）。记忆处于只读保护时不读取。
- 角色卡的描述，以及有内容时的性格和情景，最多 3000 字。
- 当前启用的世界书条目：常驻条目，以及被上述最近楼层触发的条目。读取方式与摘要读取世界书相同，遵守「排除世界书内容」设置，最多约 6000 字。读取失败时照常生成，只是不带世界书资料。
- 双子札记中已确认、尚在进行的安排，作为写作方向参考（札记功能关闭时不带），最多约 1500 字。
- 填写的要求；一键生成时为固定的说明。

读取世界书在发送请求之前进行，期间可以取消；读取期间聊天、正文或规划有变化时不发送请求。

## 推进条件检查

规划卡片中的「检查推进条件」会把当前阶段（目标、剧情要点、推进条件）和最近 6 条正文与用户原话发给规划 API，判断推进条件是否已在正文中满足。计划、约定、预告和猜测不算满足；条件含多项时需全部满足，依据不足时判为未满足。

- 判断满足时，卡片中显示依据和「切换到下一阶段」「忽略」；未满足时显示还缺什么。手动检查的结果只作提示。
- 勾选「每 N 个 AI 楼自动检查」后，每当 AI 回复数增加 N 条检查一次（默认关闭，N 默认为 3）；判断满足时在酒馆中弹出一次提示。自动检查失败不显示错误，不影响正文。
- 勾选「满足时自动切换阶段」后（默认关闭，会一并打开自动检查），自动检查判断满足时规划切换到下一阶段，卡片中显示切换所在楼层和依据，可点「退回第 N 阶段」撤回。最后一个阶段不自动结束，只提示手动结束；切换失败时改为提示。
- 每次检查请求一次规划 API。切换阶段、切换聊天或检查期间规划有变动时，迟到的结果会被丢弃；结果不保存，刷新页面后需重新检查。

## 规划讨论

「规划讨论」卡片显示讨论轮数和最近一条回复，点击「开始讨论」或「继续讨论」打开对话界面（手机上为从底部升起的面板，顶部留出状态栏，可下拉关闭；电脑上为居中窗口，可放大）。用于讨论人物动机、节奏或走向，记录按聊天保存，刷新后保留。

- 顶部「参考」选择讨论参考的版本：正在使用的规划、草稿或不参考。
- 在底部输入框填写问题，点击发送按钮或按 Ctrl+Enter 发送。等待回复时可点击停止按钮取消；请求失败时问题放回输入框。
- 消息旁显示发送和收到回复的时间。模型回复中的标题、列表和粗体按格式显示，每条回复下方可复制。右上角「更多操作」中可复制全部讨论（附时间）或清空讨论。

讨论不修改规划，也不注入正文。需要采纳时点击「生成草稿」，在弹出的面板中选择参考版本和阶段数量（1–12），确认后请求规划 API 按讨论生成新草稿，替换当前草稿（包括未保存的修改）；正在使用的规划不受影响，新草稿同样需确认后生效。生成完成后可点击「查看草稿」跳到草稿编辑器。规划 API 不可用时，对话界面中显示原因和「打开规划 API 设置」。

讨论只参考已保存的版本，编辑器中未保存的修改不会发送。每次提问最多 4000 字，回答最多 8000 字，最多保留 12 轮、共 48000 字，超出时会提示，不会自动删除旧记录。请求只附带最近约 24000 字的问答，模型可能读取不到较早的意见，重要的要求需在最新一轮重复说明。「清空讨论」只清空讨论记录，不影响草稿、规划、札记和摘要。

## 使用的 API

默认使用札记中填写的 API（无需启用札记功能），也可在「规划 API 设置」中为规划单独设置，同样支持拉取模型列表。不使用正文或摘要的 API。生成、讨论和手动检查推进条件只在点击按钮时发送请求，开启自动检查后按间隔发送；失败不自动重试。

## 长度

- 每份规划 1–12 个阶段，每个阶段 1–8 个剧情要点。
- 整份规划最多 48000 字符（包括 JSON 的标点和空白），模型的原始回复最多 100000 字符。标题 240 字，整体发展方向 4000 字，每条约束 1200 字；每个阶段的目标 2400 字、发展方式 3200 字、每条要点 1600 字、推进条件 2000 字。以上均为字符数上限，不是 token 数，也无需写满。
- 注入正文的部分（整体约束、当前阶段和固定说明）最多 16000 字符；超出时草稿仍可保存，但需精简后才能启用。

规划内容的长度上限与 API 的「最大输出」是两个独立的限制。回复被截断时，页面会说明输出达到上限，并显示当前的最大输出：使用札记的 API 时在「札记 → 独立 API 设置」中调大，使用专用 API 时在「规划 API 设置」中调大；也可减少阶段数。被截断的回复不保存为草稿。

## 格式错误

模型的回复与用户保存的编辑使用同一套检查。出错时会指出具体字段，例如 `chapters[1].approach` 指第 2 阶段的「发展方式」，并说明是缺失、类型错误、超长还是数量错误。可接受单个 json 代码块；含多余字段、JSON 不完整、夹杂其他文字的回复会被拒绝。出错不替换已有的草稿和规划，也不自动重试。

## 角色的反应

生成规划和引导正文时均强调：角色按自身的性格、动机、顾虑和已知信息行动，情绪和关系延续前文。允许犹豫、拒绝、误解和暂无结果的互动，不为推进剧情节点而突然配合、坦白、和解或翻脸，也不依靠口癖、小动作、争吵或长篇心理描写营造「活人感」。剧情节点可因人物的合理反应推迟、调整或不实现。

## 保护

- 草稿和正在使用的规划分开保存。
- 取消、切换聊天，或生成期间修改了正文或草稿时，迟到的结果不会覆盖当前内容；读取世界书期间发生这些变化时，不发送请求。
- 正常继续聊天不影响规划；改写、重抽或删除规划参考过的正文后，规划暂停生效，需核对后点击「核对后重新启用」。
- 保存失败时保留原有数据；无法识别数据版本时只读保护。
- 数据存于聊天元数据的 prism_book_outline（规划）和 prism_book_outline_discussion（讨论）。讨论记录自 prism.15 起保存每条消息的时间（第 2 版格式），之前的记录没有时间；旧版本打开带时间的讨论时只读保护，不会覆盖。规划专用 API 的设置和自动检查的开关存于扩展设置的 prism_book_outline_settings，分享设置备份前需删除密钥。
