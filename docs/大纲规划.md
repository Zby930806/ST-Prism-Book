# 大纲规划：从剧情与输入到计划

入口在 **摘要 → 计划 → 创作规划 / 大纲规划**，不是札记里的新 Q，也不新增独立导航页。

## 使用流程

1. 输入希望接下来怎样发展、节奏、必须保留的伏笔及不希望发生的事，选择规划阶段数量。
2. 点击生成。模型会只读近期剧情、用户原话、已有摘要压缩层（含 L1/L2）、人物与物品等当前状态，结合本次输入给出草稿。
3. 编辑总体方向、持续约束及每阶段的 **剧情要点、发展方式、推进条件**。
4. 保存草稿后，明确确认「加入计划」。确认前不会影响正文；新生成的草稿也不会替换之前正在使用的规划。
5. 正常回酒馆发送消息或续写。宝书会把总体约束和当前阶段注入给正文模型，不替用户自动发送消息或连续生成。下一阶段由用户切换，可随时暂停。

大纲是创作指引，不保证所有模型每轮都严格遵循。最新用户指令及已有剧情事实优先，不能为了落实大纲替用户角色作决定。若剧情已经明显偏离，可按新输入重新规划，核对后替换。

## 与原有「计划」的区别

同一个计划面板中，**剧情内计划**来自正文中的真实打算、约定；**创作规划**来自用户确认的未来写作方向。两者都可以在计划区查看，但不会混为同一种事实。

确认后的规划保存在本聊天的独立 `prism_book_outline` 数据中，计划区直接读取该真源。不复制进正文叶子的 `plans.add`，不改旧摘要、角色承诺、物品记录或 L1/L2，也不要求先生成摘要才能保存规划。这样重建摘要不会把未来大纲当历史重放，也不会擦掉规划。

当前阶段才参与正文注入，后续阶段不提前泄露。切换或结束阶段只是用户管理规划进度，**不代表那些剧情已经发生**。摘要仍然只根据正文中真正发生的事件记录变化。

## API 配置

默认复用札记已保存的 API 地址、密钥、模型及请求参数，但使用大纲自己的提示词和数据，**无需启用札记生成开关**。也可切换为大纲专用 OpenAI 兼容 API，单独拉取模型列表、搜索选择或手动填模型。

不会回退正文或摘要 API。生成由用户手动触发，不自动重试或自动连续规划。专用设置保存在 `prism_book_outline_settings`；分享酒馆设置备份前请移除密钥。

## 保护与限制

- 每份规划 1～12 阶段，每阶段 1～8 个剧情要点；总内容最多 24000 字。注入当前阶段与全局约束最多 12000 字，超限需精简，不静默砍掉约束。
- 生成、编辑后的草稿与已确认规划分开保存；草稿替换不自动改变当前指引。
- 取消、切聊天、生成期间编辑正文或修改草稿后，迟到的生成结果不覆盖新状态。
- 普通追加剧情不会让现有规划失效；改写、重抽、删除其参考的历史正文会停止注入，须用户核对后重新启用。
- 保存失败保留原数据，可重试；未知数据版本进入只读保护，不自动覆盖。
- 只支持本地模拟宿主验证，不代表已经在所有酒馆版本、预设和手机上实机验收。
