# 公开仓库发布与安装

维护者已选择Public。文件名沿用旧版以保持已有链接兼容，不再要求私有发布。

## 网页上传

1. 在自己的目标仓库根目录选择Add file → Upload files。
2. 每批打开本机提供的批次文件夹，全选其内部文件和文件夹后拖到上传区。不要拖最外层批次文件夹，不要上传ZIP作为唯一仓库内容。
3. 第一批提交后回到仓库根目录，以同样方式上传第二批。两批相对路径合并为完整项目，不能互相替代。
4. 提交前核对文件清单，不添加聊天、settings.json、.env、凭据、node_modules、备份和验证日志。
5. 完成后根目录必须直接包含manifest.json、README.md、src、dist等；dist含index.js、index.css和index.js.map。

## 安装与更新

公开仓库内容完整后，成员可以用仓库地址安装；手动安装仍参照README。不要同时启用原版和本版。它们保留同一数据键、宏和事件。

本版保留“重建本聊天记忆”，不会安装后自动重建；需用户手动确认，按楼序调用模型，可能产生费用并替换已有摘要与手动状态更新，先备份。

仍不启用上游一键更新、Pages、自动Release或自动部署。package.json的private: true防止误发npm，与GitHub可见性无关。

公开仓库不应写入授权私聊截图、私人联系方式或令牌。仅上传已经审查的发行内容。
