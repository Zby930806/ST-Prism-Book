# 常见报错

摘要、札记、创作规划和连接测试出错时，提示依次说明错误内容、处理方法和对应的设置位置。服务商返回的原文显示在可展开的「技术细节」中；其中的密钥和带参数的地址会被遮盖，整页 HTML 只显示网页标题。

## 回复被截断

提示类似：「回复被截断：输出达到长度上限，模型没写完就停了。当前最大输出是 3000 tokens……」

本次回复达到了最大输出（max_tokens）。思考型模型的思考过程也计入其中。

处理方法：

- 在提示所写的位置调大「最大输出」：
  - 摘要和总结：设置 → 副 API → 对应的渠道
  - 札记：札记 → 独立 API 设置
  - 创作规划：使用札记的 API 时在「札记 → 独立 API 设置」，使用专用 API 时在「规划 API 设置」
  - 向量记忆的 Query 重写：设置 → 向量记忆
- 已调到较大值仍被截断，说明服务商限制了单次输出，需更换输出上限更高的模型或渠道。
- 启用了思考强度时，调低思考强度也有帮助。

截断后的处理：

- 摘要：截断发生在 JSON 已完整输出之后时，结果照常使用；否则该楼不保存，原摘要不变。此类错误不自动重试，重试同样会被截断。
- 札记：保存已生成的部分，末尾标明「被截断」，页面提示内容不完整。
- 创作规划：不保存不完整的草稿。
- 连接测试：显示「连接正常，但测试回复被截断」。

另一种情况是「模型的输出额度在思考阶段就用完了，正文还没开始写」，即思考过程耗尽了最大输出。需调大最大输出，或调低思考强度。

使用「跟随主 API」时无法获取结束原因，只能根据不完整的 JSON 判断截断。此时可为摘要指派副 API 渠道，单独设置最大输出。

## 没有正文 / 返回空内容

- 「模型只输出了思考过程，没有给出正文」：重试或更换模型；启用了思考强度时先调低。
- 「API 返回了空内容」：可能是模型拒答、被内容审核静默拦截，或接口与流式输出不兼容。重试，或切换渠道的「流式传输」开关。

## 密钥、额度、限流

- 「API 密钥无效或没有权限（HTTP 401 / 403）」：检查密钥是否填错、是否过期，以及该密钥能否使用所选模型。
- 「账户余额或额度不足」：在服务商后台查看余额，或更换渠道。
- 「请求太频繁，被服务商限流（HTTP 429）」：稍后重试；批量补摘可分多次进行。

密钥和额度问题不自动重试。

## 地址和模型

- 「接口地址不对（HTTP 404）」「这个地址不接受该请求（HTTP 405）」：OpenAI 兼容接口的地址一般以 /v1 结尾，检查路径是否多写或少写。连接测试会自动尝试另一种 /v1 写法。
- 「模型不存在，或当前密钥不能使用这个模型」：核对模型名，可通过「拉取模型列表」选择。
- 「API 返回的不是有效数据」：地址可能指向网站首页而非接口。

## 请求被拒绝

- 「发送的内容超出了模型的上下文长度」：更换上下文更长的模型，或减少单次发送的内容，如调小「记忆注入预算」、札记的参考楼层数。部分接口将最大输出计入上下文，调小「最大输出」也可能有效。
- 「这个接口不接受「预填充」消息」：在渠道设置中关闭「发送预填充」。
- 「最大输出超过了这个模型的上限」：「最大输出」超过了模型允许的值（如部分模型最多 8192 或 4096 tokens）。将其调小到模型支持的范围；技术细节中通常可看到服务商给出的上限。
- 「服务商拒绝了这次请求（HTTP 400 / 422）」：常见原因是模型名错误、最大输出超过模型上限，或接口不支持某个参数。可核对模型名、调小「最大输出」；使用副 API 渠道时，还可将不支持的参数填入渠道的「排除参数」（如 temperature），或关闭「发送预填充」。酒馆的非流式代理不转发服务商原文，无法判断具体原因时，启用「流式传输」后重试通常可以看到。
- 「请求被服务商的内容审核拦截了」「回复写到一半被服务商的内容审核截断了」：更换模型或渠道后重试。

## 服务商和网络

- 「服务商出错（HTTP 5xx）」「服务商中途中断了回复」：通常是服务商临时故障或过载，稍后重试。
- 「服务商处理超时」「……超时（超过 N 秒）」：服务商繁忙或内容过长，可在对应的 API 设置中调大超时。
- 「酒馆连不上 API 服务器」「找不到 API 服务器（域名解析失败）」「API 服务器拒绝连接」「连接 API 时证书校验失败」：检查地址拼写、端口和 http / https，以及运行酒馆的电脑能否访问该服务；需要代理时，确认酒馆能通过代理访问。
- 「连不上酒馆服务器」：酒馆可能已关闭或网页已断线，确认后刷新页面。
- 「浏览器无法访问这个地址」（向量记忆）：向量接口由浏览器直接访问，除地址和网络问题外，也可能是服务商不允许网页跨域访问（CORS）。
- 「API 返回了错误，但酒馆没有转发具体原因」：酒馆的非流式代理只转发了状态，未转发原因。启用渠道的「流式传输」后重试，通常可以看到服务商原文；也可查看运行酒馆的命令行窗口。

## 摘要特有的提示

- 「楼层 #N 摘要未完成：……」：请求阶段出错，原因见冒号后的内容。已有记录不变。
- 「第 #N 楼的摘要没有保存：……」：模型已回复，但内容未通过检查（如伤势、位置的引文不匹配，或格式错误）。该楼不写入，可单独重试，无需重建整个聊天。伤势和位置证据的问题见 [摘要证据校验说明](摘要证据校验说明.md)。
- 「摘要超出字数上限」已不再出现：自 prism.9 起，摘要超过「摘要字数」也照常保存。需要更短的摘要时，调小「设置 → 摘要设置 → 摘要字数」。
- 「还没有可用的 API」：摘要未指派副 API 渠道，酒馆的主 API 也无法连接。在「设置 → 副 API」中添加并指派渠道，或先连接主 API。
