# 常见报错

摘要、札记、创作规划和连接测试出错时，提示会先说发生了什么，再说怎么处理、该去哪个设置里改。服务商返回的原话放在可以展开的「技术细节」里；其中的密钥和带参数的地址会被遮住，整页 HTML 只显示网页标题。

## 回复被截断

提示类似：**回复被截断：输出达到长度上限，模型没写完就停了。当前最大输出是 3000 tokens……**

模型这次能写的长度（最大输出，也就是 max_tokens）用完了。思考型模型的思考过程也算在里面。

怎么办：

- 到提示里写的位置调大「最大输出」：
  - 摘要和总结：设置 → 副 API → 对应的渠道
  - 札记：札记 → 独立 API 设置
  - 创作规划：用札记的 API 时在「札记 → 独立 API 设置」，用专用 API 时在「规划 API 设置」
  - 向量记忆的 Query 重写：设置 → 向量记忆
- 已经调得很大还是被截断，说明服务商限制了单次输出，换一个输出上限更高的模型或渠道。
- 开着思考强度的话，调低它也有帮助。

被截断之后：

- 摘要：如果截断发生在 JSON 已经写完之后，结果照常使用；否则这一楼不保存，原来的摘要不变。这种错误不会自动重试，重试也会被截断。
- 札记：已写出的部分会保存，末尾标明「被截断」，页面提示内容不完整。
- 创作规划：不保存残缺的草稿。
- 连接测试：显示「连接正常，但测试回复被截断」。

还有一种情况：**模型的输出额度在思考阶段就用完了，正文还没开始写**。也就是思考把最大输出全用光了。调大最大输出，或调低思考强度。

用「跟随主 API」时拿不到结束原因，只能从写到一半的 JSON 判断出被截断。这时可以给摘要指派一个副 API 渠道，单独设置最大输出。

## 没有正文 / 返回空内容

- **模型只输出了思考过程，没有给出正文**：重试，或换个模型；开着思考强度的话先调低。
- **API 返回了空内容**：可能是模型拒答、被内容审核悄悄拦下，或者接口和流式输出不兼容。重试，或切换渠道的「流式传输」开关。

## 密钥、额度、限流

- **API 密钥无效或没有权限（HTTP 401 / 403）**：检查密钥有没有填错、有没有过期，以及这个密钥能不能用所选的模型。
- **账户余额或额度不足**：到服务商后台看余额，或者换个渠道。
- **请求太频繁，被服务商限流（HTTP 429）**：等一会儿再试；批量补摘可以分几次做。

密钥和额度问题不会自动重试。

## 地址和模型

- **接口地址不对（HTTP 404）**、**这个地址不接受该请求（HTTP 405）**：OpenAI 兼容接口的地址一般以 /v1 结尾，检查是不是多写或少写了路径。连接测试会自动试另一种 /v1 写法。
- **模型不存在，或当前密钥不能使用这个模型**：核对模型名，可以用「拉取模型列表」选一个。
- **API 返回的不是有效数据**：地址可能指向了网站首页，而不是接口。

## 请求被拒绝

- **发送的内容超出了模型的上下文长度**：换一个上下文更长的模型，或者减少一次发送的内容，比如调小「记忆注入预算」、札记的参考楼层数。有些接口会把最大输出也算进上下文，调小「最大输出」也可能有用。
- **这个接口不接受「预填充」消息**：在渠道设置里关掉「发送预填充」。
- **最大输出超过了这个模型的上限**：「最大输出」设得比模型允许的还大（比如有的模型最多只能写 8192 或 4096 tokens）。把它调小到模型支持的范围；技术细节里一般能看到服务商写的上限。
- **服务商拒绝了这次请求（HTTP 400 / 422）**：常见原因是模型名不对、最大输出超过了模型的上限，或者接口不支持某个参数。可以核对模型名、调小「最大输出」；用副 API 渠道时，还可以把不支持的参数填进渠道的「排除参数」（例如 temperature），或关掉「发送预填充」。酒馆的非流式代理不转发服务商的原话，看不出具体原因时，打开「流式传输」再试一次通常就能看到。
- **请求被服务商的内容审核拦截了**、**回复写到一半被服务商的内容审核截断了**：换个模型或渠道再试。

## 服务商和网络

- **服务商出错（HTTP 5xx）**、**服务商中途中断了回复**：多半是服务商临时故障或过载，稍后重试。
- **服务商处理超时**、**……超时（超过 N 秒）**：服务商繁忙或者内容太长，可以在对应的 API 设置里调大超时。
- **酒馆连不上 API 服务器**、**找不到 API 服务器（域名解析失败）**、**API 服务器拒绝连接**、**连接 API 时证书校验失败**：检查地址的拼写、端口和 http / https，以及运行酒馆的电脑能不能访问这个服务；需要代理的话，确认酒馆能走代理。
- **连不上酒馆服务器**：酒馆可能已经关了，或者网页断线了，确认后刷新页面。
- **浏览器无法访问这个地址**（向量记忆）：向量接口由浏览器直接访问，除了地址和网络，也可能是服务商不允许网页跨域访问（CORS）。
- **API 返回了错误，但酒馆没有转发具体原因**：酒馆的非流式代理只转发了状态，没有转发原因。打开渠道的「流式传输」再试一次，通常能看到服务商的原话；也可以看运行酒馆的命令行窗口。

## 摘要特有的提示

- **楼层 #N 摘要未完成：……**：请求这一步出了问题，原因见冒号后面。已有的记录不变。
- **第 #N 楼的摘要没有保存：……**：模型回复了，但内容没通过检查（比如伤势、位置的引文对不上，或格式不对）。这一楼不写入，可以单独重试，不需要重建整个聊天。伤势和位置证据的问题见 [摘要证据校验说明](摘要证据校验说明.md)。
- **还没有可用的 API**：摘要没有指派副 API 渠道，酒馆的主 API 也连不上。到「设置 → 副 API」添加并指派渠道，或者先连好主 API。
