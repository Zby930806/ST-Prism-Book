# 品牌图标

标题栏和默认的悬浮球用一只小狐狸作标志，旁边是「棱镜宝书」四个字。

- 狐狸是 PrismFox 的小狐狸（坐姿），取自「双人成行」预设脚本里的悬浮宠物。原图是 110×128 的 PNG，去掉了右边缘一处和身体不相连的切图残留，裁掉四周透明边后是 96×128。
- 图片以 data URI 内嵌在源码里（src/components/foxSprite.ts，由 BrandMark.vue 使用），不依赖外部图片，也不需要单独的图片文件。
- 颜色固定为狐狸本色，换主题时不变。
- 你自己上传的悬浮球图片优先，不会被替换。
- 文件名沿用以前的，免得链接失效；不改变原项目的归属和授权。
