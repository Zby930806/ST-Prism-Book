# 界面设计与使用边界

版本：1.2.9-prism.3；日期：2026-10-07。

## 设计方向
深靛蓝与柔和紫色形成夜间基调，琥珀用于待办提示。标题、说明、内容和操作保持明确层级，不用大量装饰替代可操作内容。日间、粉彩、木白与跟随 ST 同样保留。

## 六个页面
- 摘要与计划：实时记忆计数、可展开的健康兼容说明、当前局势、计划/悬念、总结树。正常状态的解释默认折叠；转换或保护问题始终明确显示。
- 物品：计数、搜索、随身/存放筛选、条目编辑。无有效叶子时明确禁止添加，避免无处保存。
- 场景：当前位置、完整路径与树导航；保留增改删与搬移，前往仅追加宿主草稿。
- 角色：主角档案、角色名册、分组与搜索、轻量生活信息；不移除临时伤势等既有字段。
- 变量：当前状态与模板编辑分开，保留全局/角色/聊天三层、结构与源码。
- 设置：常用设置、记忆与召回、提示词工作台、高级过滤、数据与迁移；配置概览可展开，不能被误读为 API 已连接。

## 操作与保护
手机顶部和底部均显示六个中文导航名称。沿用用户的自动/顶部/底部设置与重复点击当前页关闭选项。默认浮球使用书签图标；已有自定义图优先。

弹窗首次聚焦容器而非危险按钮，Tab 在当前层循环；Esc 关闭当前层并恢复触发焦点。繁忙确认期间不能再次确认或取消。收起的面板与总结下层设为 inert，不能误 Tab 进入。

重建入口位于摘要页底部的高级维护区，功能、费用警告和二次确认保留。升级不要求重建。

## 数据与兼容不变
本轮不修改 memory/public 核心、九份内置提示词、存储键或 API。保留 prism.2 的旧摘要、L1/L2 总结、有限本地转换及未知格式保护。旧版与本版不得同时启用。

## 验证范围
真实源码组件在独立模拟宿主的 Shadow DOM 中验证；包含六页、桌面与 390px / 320px 窄屏、五主题、空态、保护状态、弹窗与主要键盘路径。固定主题主要文字 token 测量对比度；跟随 ST 由宿主颜色决定，不能承诺任意宿主主题都满足对比度。

未覆盖所有酒馆版本、真实模型、触屏真机或所有辅助技术。完整候选包仍应先在聊天副本进行实机验收。
