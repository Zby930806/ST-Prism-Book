# 界面说明

版本：1.2.9-prism.16（2026-10-20）

## 风格

- 标题栏和默认悬浮球使用 PrismFox 的小狐狸图标；书名和各页标题使用衬线字体，正文和表单使用无衬线字体。
- 夜间主题以深色为底、暖橙色为强调色；另有日间、粉彩、木白和「跟随 ST」。沿用原主题 ID，保留用户已选的主题。
- 各页共用一套部件：次要按钮（浅底细边，悬停时显示强调色）、主按钮（实心强调色）、危险按钮、图标按钮、分段选择、弹窗（标题栏、关闭键、底部操作）、空状态、统计行、提示条（警告、错误、成功）、带箭头的折叠行（箭头在行尾，收起朝下、展开朝上，整行可点）、拨动开关。同类控件的尺寸、圆角和字号一致：字号分 11、12、13、14、16、20、26px 七档；电脑上控件高 36px，小号按钮 32px；手机和平板等触屏设备上，按钮、图标按钮、分段选择和下拉框为 40px。
- 报错统一使用红色提示条，服务商原文收在「技术细节」中。影响多条记录或不可恢复的删除弹出确认框；楼层面板和札记卡片的删除在原位确认。
- 停用、番外、已处理等状态用颜色和虚线边表示，不降低整体透明度，文字保持可读。
- 说明文字只写「是什么、会怎样、去哪改」，不写标语。较长的说明只显示要点，其余收进「详细说明」。

## 各页

- 摘要：顶部显示逐楼摘要、总结和待补摘的数量，旁边是常驻的「补摘」按钮（有漏摘楼层时可用）；下方是「楼层光谱」，每层 AI 回复一格，按发原文、逐楼摘要、已并入总结、已并入二次总结分档，越早压缩越多颜色越淡，待补摘为条纹，番外为斜线，悬停一段显示楼层范围。有漏摘时列出「未摘要楼层」，连续的楼层合为一段，单层点击直接补摘，多层的一段打开批量补摘确认、只补这一段。其下是两条折叠行：「当前局势与计划」，行内显示计划与悬念的数量和局势一句话，展开为局势卡、计划和悬念；「创作规划」，行内显示阶段与状态，展开为当前规划、推进条件检查、「规划讨论」入口和「修改或重新生成规划」。再往下是摘要与总结列表，工具行有搜索、多选和立即总结（没有摘要时不可用）；底部为开场时间、导入旧总结、旧记忆兼容和重建记忆。编辑摘要时，输入框下方显示字数（仅作提示，不限制保存）。批量补摘的确认框中，待补摘达到 30 层时可在「较早楼层合并摘要」和「全部逐层摘要」之间切换，前者可修改逐层摘要的最近楼层数和每次合并的楼层数，并显示请求次数；合并生成的摘要在列表中标注「简要」。批量补摘或重建时显示进度条、当前阶段、每楼（合并时为每次请求）大致耗时和剩余时间。
- 规划讨论：从「创作规划」中的「规划讨论」卡片打开。手机上为从底部升起的面板，顶部留出状态栏，可点返回或下拉顶部的拖动条关闭；电脑上为居中窗口，可放大。标题栏有返回、放大和更多操作（复制全部讨论、清空讨论），其下选择讨论参考的版本。消息按对话排列，说话人旁显示时间；模型回复中的标题、列表和粗体按格式显示，每条回复可复制。底部为讨论轮数、「生成草稿」和输入栏；等待回复时可停止。「生成草稿」从底部弹出面板，选择参考版本和阶段数量后确认，完成后可跳到草稿编辑器。
- 楼层面板：卡片头部显示楼号、时间和小标签（召回段数、不一致），右侧依次为展开箭头、番外键（点一下标为番外，再点一下取消）和单楼摘要键（没有摘要时生成，已有摘要时重新生成）；点击头部或按 Enter、空格展开，展开后头部不再重复摘要预览和时间。展开后依次为时间、地点（本楼没有记录地点时，以浅底、次要色显示最近一次记录的地点，点击可为本楼单独设置）、摘要正文（点击或用键盘进入编辑）、各类变动（按「图标 + 标题 + 细线」分组）、记录冲突和召回记录，底部为「生成摘要 / 重新生成摘要」和「删除摘要」（在原位确认）。重新生成时，新结果先与现有摘要并排对比（摘要正文、时间和状态变化），选择「用新的」后才替换；手机上两份上下排列，选择按钮固定在底部。番外楼为虚线边框，番外键显示为按下，展开后顶部说明此楼不参与记忆，底部不显示按钮。正文与已有记录不一致时，头部标注「不一致」，面板中列出记录与正文原句，可选「提醒正文模型」或「忽略」。批量补摘时合并生成的摘要，面板中注明只有摘要和时间、未记录状态变动。
- 札记卡片：启用双子札记时，显示在最新一条回复和有札记的楼层下方，头部、抽屉、分区标题和页脚与楼层面板相同；页脚右侧为「删除札记」，在原位确认，写明一起删除的安排数。
- 物品、场景、角色、变量：页头为一句说明，下方为统计行和各自的列表、搜索和编辑。角色页依次为主角、NPC 名册、生活小档案和信息差：角色卡的操作键与名字同一行，字段标签为次要色，位置以易读的方式显示，例如「跟主角在一起」「现在不确定；最后一次在旧街」；生活小档案、信息差没有条目时缩成一行，展开后显示投放规则；信息差可结案、重开或删除。删除生活细节、信息差和物品前需要确认。场景页地点卡的操作在标题行右侧，窄屏时在卡片末尾。
- 札记：上方为启用开关和生成按钮，中间为札记和已确认的安排，独立 API 设置、自动生成与注入、原版提示词、导入位于底部。每份札记展开后底部有「删除札记」，弹窗确认，写明一起删除的安排数和其中正在注入的条数。操作结果显示在对应按钮旁。
- 设置：总开关和分组目录，其后为常用设置（副 API、札记与规划 API、基本设置、摘要设置）、记忆与召回（注入设置、向量记忆、召回调试）、提示词、高级过滤、数据与迁移。各卡片默认收起，点击标题展开；仅在时间标签提示词超出预算时，「注入设置」自动展开并显示警告。「札记与规划 API」显示两项 API 是否已设置及所用模型，按钮切到对应页面并展开 API 设置。「摘要设置」中第一个数字项为「摘要字数」，其下的「字数档位」只影响总结和二次总结。「自定义提示词」中，修改后内置版本又有更新的提示词标有「内置已更新」，打开可查看差异；说明中注明模型名含 deepseek 时不发送内容边界。「向量记忆 → 召回参数」中有关键词召回、在场角色加权和召回保留轮数；关闭向量记忆时，相关设置以浅底和次要色表示停用。「召回调试」分五步逐行展开，行尾显示数量，顶部为与「召回」速览相同的结果说明；列出关键词命中，第 4 步标注每段来自哪一路，并以「超出预算」「原文超出预算」标出受召回预算影响的段落。「注入设置」中有「信息差」开关。

## 快捷回复栏

- 启用向量记忆时，输入框上方的快捷回复栏显示「召回」按钮，按钮上显示上次召回的段数（召回中、未召回、召回失败时显示对应状态）。点击后弹出召回速览，显示每段的来源楼层、故事时间、注入的是全文还是摘要以及内容预览；「注入原文」为可折叠的一行。没有召回记录时显示说明。点击外部、按 Esc、点关闭键或再次点击按钮时收起；用 Esc 或关闭键收起后，焦点回到「召回」按钮。可在「设置 → 基本设置 → 在快捷回复栏显示召回」中关闭。

## 手机

- 导航可置于顶部或底部，名称均显示中文；可设置为再次点击当前页导航时关闭窗口。
- 窗口从底部弹出，可下滑关闭；窄屏和触屏上按钮、标签和滑块加大，便于点按。规划讨论在手机上从底部升起，顶部留出状态栏，可下拉关闭；「生成草稿」面板从底部弹出。
- 避开状态栏：宝书窗口和规划讨论顶部留出 4% 的高度；页面画到状态栏下面时（安全区不为 0），改为状态栏高度再加 8px，取两者中较大的。弹窗上下让出状态栏和底部手势条，再高也不超出这一范围，标题栏和关闭键始终在状态栏下方；悬浮球不会停在状态栏或手势条下面。

## 键盘与读屏

- 弹窗打开时焦点位于弹窗内（有自动聚焦的输入框时停在输入框），Tab 在弹窗内循环，Esc 逐层关闭并将焦点返回原按钮。
- 收起的内容不会被 Tab 选中。楼层面板和札记卡片的头部可用 Enter、空格展开。
- 图标按钮带读屏名称；开关读作开关；下拉选择可用方向键移动、回车确认，Esc 只收起列表。

## 检查方式

界面在本地测试页面中检查：使用真实组件和虚构的演示数据，在 1280px、390px 和 320px 宽度及夜间、日间主题下截图核对，确认无横向溢出和页面报错；手机宽度下另模拟状态栏、底部手势条和软键盘弹出，逐个打开窗口、弹窗和菜单，确认退出键可点。未在所有酒馆版本、手机真机和辅助技术上测试；「跟随 ST」主题的颜色由酒馆决定，不能保证所有主题下的对比度。
