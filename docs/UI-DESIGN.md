# 界面说明

版本：1.2.9-prism.8（2026-10-09）

## 风格

- 标题栏和默认悬浮球用小狐狸标志，书名和各页标题用衬线字体，正文和表单用无衬线字体。
- 夜间主题以深色为底，暖橙色作强调；另有日间、粉彩、木白和「跟随 ST」。主题 ID 和你原来的选择不变。
- 次要按钮是浅底细边，悬停才带强调色；主按钮是实心的强调色。输入框聚焦时有一圈柔和的光晕。
- 各页共用几种部件：提示条（警告、错误、成功）、带箭头的折叠行、拨动开关。报错统一用红色提示条，服务商的原话收在「技术细节」里。
- 说明文字只写「是什么、会怎样、去哪改」，不写标语。

## 各页

- **摘要**：顶部是逐楼摘要、总结和待补摘的数量，旁边是常驻的「补摘」按钮（有漏摘的楼层时才能点）；有漏摘时下面列出「未摘要楼层」，可以点楼层号单独补，或批量补摘。「当前局势与计划」可以展开，里面有局势卡、计划、悬念和创作规划；下面是摘要与总结列表；底部是开场时间、旧记忆兼容和重建记忆。
- **物品、场景、角色、变量**：页头一句说明，下面是各自的列表、搜索和编辑。角色名册里的位置用好读的说法显示，例如「跟主角在一起」「现在不确定；最后一次在旧街」。
- **札记**：上面是启用开关和生成按钮，中间是札记和已确认的安排，独立 API 设置、自动生成与注入、原版提示词、导入放在底部。操作结果显示在对应的按钮旁边。
- **设置**：总开关和分组目录，然后是常用设置、记忆与召回、提示词、高级过滤、数据与迁移。

## 手机

- 导航可以放在顶部或底部，名称都显示中文；可以设置再点当前页导航就关闭窗口。
- 窗口从底部弹出，可以下滑关闭；按钮在窄屏上加高，方便点按。

## 键盘

- 弹窗打开时焦点落在弹窗上，Tab 在弹窗里循环，Esc 逐层关闭并回到原来的按钮。
- 收起的内容不会被 Tab 选中。

## 怎么检查的

界面在本地测试页面里检查：用真实的组件和虚构的演示数据，在 1280px、390px 和 320px 宽度、夜间和日间主题下截图核对，确认没有横向溢出和页面报错。没有在所有酒馆版本、手机真机和辅助技术上测试；「跟随 ST」主题的颜色由酒馆决定，不能保证任何主题下对比度都合适。
