# 界面说明

版本：1.2.9-prism.14（2026-10-15）

## 风格

- 标题栏和默认悬浮球使用 PrismFox 的小狐狸图标；书名和各页标题使用衬线字体，正文和表单使用无衬线字体。
- 夜间主题以深色为底、暖橙色为强调色；另有日间、粉彩、木白和「跟随 ST」。沿用原主题 ID，保留用户已选的主题。
- 次要按钮为浅底细边，悬停时显示强调色；主按钮为实心强调色。输入框聚焦时显示一圈柔和的光晕。
- 各页共用的部件：提示条（警告、错误、成功）、带箭头的折叠行、拨动开关。报错统一使用红色提示条，服务商原文收在「技术细节」中。
- 说明文字只写「是什么、会怎样、去哪改」，不写标语。

## 各页

- 摘要：顶部显示逐楼摘要、总结和待补摘的数量，旁边是常驻的「补摘」按钮（有漏摘楼层时可用）；有漏摘时下方列出「未摘要楼层」，可点击楼层号单独补摘，或批量补摘。「当前局势与计划」可展开，包含局势卡、计划、悬念和创作规划；创作规划卡片中有「检查推进条件」和自动检查间隔，判断满足时显示依据和「切换到下一阶段」。其下为摘要与总结列表；底部为开场时间、旧记忆兼容和重建记忆。编辑摘要时，输入框下方显示字数（仅作提示，不限制保存）。批量补摘的确认框中，待补摘达到 30 层时可在「较早楼层合并摘要」和「全部逐层摘要」之间切换，前者可修改逐层摘要的最近楼层数和每次合并的楼层数，并显示请求次数；合并生成的摘要在列表中标注「简要」。批量补摘或重建时，进度旁显示当前阶段、每楼（合并时为每次请求）大致耗时和剩余时间。
- 楼层面板：重新生成某楼摘要时，新结果先与现有摘要并排对比（摘要正文、时间和状态变化），选择「用新的」后才替换；手机上两份上下排列，选择按钮固定在底部。启用向量记忆时，面板底部显示生成本楼前的召回记录（来源楼层、故事时间、注入方式和内容预览），卡片头部标注召回段数或「召回失败」。正文与已有记录不一致时，卡片头部标注「不一致」，面板中列出记录与正文原句，可选「提醒正文模型」或「忽略」。变动中新增「信息差」一组。批量补摘时合并生成的摘要，面板中注明只有摘要和时间、未记录状态变动。
- 物品、场景、角色、变量：页头为一句说明，下方为各自的列表、搜索和编辑。角色名册中的位置以易读的方式显示，例如「跟主角在一起」「现在不确定；最后一次在旧街」。角色页的「信息差」默认收起，列出未结案和已结案的条目，可结案、重开或删除。
- 札记：上方为启用开关和生成按钮，中间为札记和已确认的安排，独立 API 设置、自动生成与注入、原版提示词、导入位于底部。操作结果显示在对应按钮旁。
- 设置：总开关和分组目录，其后为常用设置、记忆与召回、提示词、高级过滤、数据与迁移。各卡片默认收起，点击标题展开；仅在时间标签提示词超出预算时，「注入设置」自动展开并显示警告。「摘要设置」中第一个数字项为「摘要字数」，其下的「字数档位」只影响总结和二次总结。「自定义提示词」中，修改后内置版本又有更新的提示词标有「内置已更新」，打开可查看差异。「向量记忆 → 召回参数」中有关键词召回、在场角色加权和召回保留轮数；「上次召回详情」分五步显示，列出关键词命中，并标注每段来自哪一路。「注入设置」中有「信息差」开关。

## 快捷回复栏

- 启用向量记忆时，输入框上方的快捷回复栏显示「召回」按钮，按钮上显示上次召回的段数（召回中、未召回、召回失败时显示对应状态）。点击后弹出召回速览，显示每段的来源楼层、故事时间、注入的是全文还是摘要以及内容预览，可展开查看注入原文。点击外部、按 Esc 或再次点击按钮时收起。可在「设置 → 基本设置 → 在快捷回复栏显示召回」中关闭。

## 手机

- 导航可置于顶部或底部，名称均显示中文；可设置为再次点击当前页导航时关闭窗口。
- 窗口从底部弹出，可下滑关闭；窄屏上按钮加高，便于点按。

## 键盘

- 弹窗打开时焦点位于弹窗内，Tab 在弹窗内循环，Esc 逐层关闭并将焦点返回原按钮。
- 收起的内容不会被 Tab 选中。

## 检查方式

界面在本地测试页面中检查：使用真实组件和虚构的演示数据，在 1280px、390px 和 320px 宽度及夜间、日间主题下截图核对，确认无横向溢出和页面报错。未在所有酒馆版本、手机真机和辅助技术上测试；「跟随 ST」主题的颜色由酒馆决定，不能保证所有主题下的对比度。
