# 界面说明

版本：1.4.0（2026-10-23）

## 风格

- 标题栏和默认悬浮球使用 PrismFox 的小狐狸图标；书名和各页标题使用衬线字体，正文和表单使用无衬线字体。
- 夜间主题以深色为底、暖橙色为强调色；另有日间、粉彩、木白和「跟随 ST」。沿用原主题 ID，保留用户已选的主题。
- 各页共用一套部件：次要按钮（浅底细边，悬停时显示强调色）、主按钮（实心强调色）、危险按钮、图标按钮、分段选择、弹窗（标题栏、关闭键、底部操作）、空状态、统计行、提示条（警告、错误、成功）、带箭头的折叠行（箭头在行尾，收起朝下、展开朝上，整行可点）、拨动开关。同类控件的尺寸、圆角和字号一致：字号分 11、12、13、14、16、20、26px 七档；电脑上控件高 36px，小号按钮 32px；手机和平板等触屏设备上，按钮、图标按钮、分段选择和下拉框为 40px。
- 报错统一使用红色提示条，服务商原文收在「技术细节」中。影响多条记录或不可恢复的删除弹出确认框；楼层面板和札记卡片的删除在原位确认。
- 停用、番外、已处理等状态用颜色和虚线边表示，不降低整体透明度，文字保持可读。
- 说明文字只写「是什么、会怎样、去哪改」，不写标语。较长的说明只显示要点，其余收进「详细说明」。

## 各页

- 摘要：顶部显示逐楼摘要、总结和待补摘的数量，旁边是常驻的「补摘」按钮（有漏摘楼层时可用）和次要样式的「全部重新摘要…」按钮（还没有摘要、正在摘要或记忆受保护时停用；窄屏时两个按钮另起一行，两列等宽）；下方是「楼层光谱」，每层 AI 回复一格，按发原文、逐楼摘要、已并入总结、已并入二次总结分档，越早压缩越多颜色越淡，待补摘为条纹，番外为斜线，悬停一段显示楼层范围。全部重新摘要没有完成时，概览下方显示警告色提示条「全部重新摘要未完成：已完成 X/Y 层，停在 #N」，附一行说明和「继续」「结束」两个按钮，「结束」先弹出确认框，写明保留新结果和保留原摘要的层数；范围内都已完成、记录还在时显示「全部重新摘要已完成：X/Y 层」和「知道了」；处理期间不显示提示条。有漏摘时列出「未摘要楼层」，连续的楼层合为一段，单层点击直接补摘，多层的一段打开批量补摘确认、只补这一段。清洗后没有正文的楼层单独列在下方，楼层号旁为「标为番外」按钮。其下是两条折叠行：「当前局势与计划」，行内显示计划与悬念的数量和局势一句话，展开为局势卡、计划和悬念（删除计划或悬念先弹出确认框）；「创作规划」，行内显示阶段与状态（参考的正文有改动时为「剧情有改动，已暂停」），展开为当前规划、推进条件检查（自动检查没有完成时下方显示一条警告色说明）、「规划讨论」入口和「修改或重新生成规划」；草稿编辑器中，超出注入上限的阶段在阶段下拉中标「超出注入上限」，下方显示警告条；生成草稿时自动调整过的地方列在草稿上方的警告条中；「规划 API 设置」的数值行下方有一行最大输出的说明；没有规划和草稿时，当前规划的位置为「一键生成规划」卡片（一句说明和「一键生成」，生成中按钮显示「生成中…」，旁边为「取消生成」，下方显示正在生成的内容；未设置规划 API 时按钮停用，显示原因和「打开规划 API 设置」）；「生成规划草稿」中阶段数和生成键旁有「一键生成」，其下一行说明不使用上方的要求和阶段数，已有规划或草稿时点击后先显示替换确认；一键生成完成后自动展开并滚动到草稿编辑器；当前阶段的「推进条件」一行和「全部阶段」里每个阶段的推进条件后有编辑键，打开「修改推进条件」弹窗；推进条件检查一行为「检查推进条件」、每 N 个 AI 楼自动检查和「满足时自动切换阶段」（自动检查关闭时以次要色表示不起作用），自动切换后显示切换的楼层、依据和「退回第 N 阶段」，其下的说明写明发送范围（本阶段上次检查以来、至少最近 max(6, 间隔×2) 条）。再往下是摘要与总结列表，工具行有搜索、多选和立即总结（没有摘要时不可用）；总结因截断等原因暂停自动重试时，工具行下方显示警告提示条，写明原因并提供「重试总结」；标题旁的「估算注入量」展开后分行列出摘要注入、其他注入、召回注入（上一次）、札记安排、创作规划、连续性提醒（后四项有内容时显示）和合计；底部为开场时间（已有摘要、没有故事时间的旧聊天显示为「当前故事时间」，可设定截至最新一层摘要的时间）、导入旧总结和旧记忆兼容。编辑摘要时，输入框下方显示字数（仅作提示，不限制保存）。批量补摘的确认框中，待补摘达到 30 层时可在「较早楼层合并摘要」和「全部逐层摘要」之间切换，前者可修改逐层摘要的最近楼层数和每次合并的楼层数，并显示请求次数；其下一行说明一组没写全时先保存写好的楼层、其余对半拆开重试；合并生成的摘要在列表中标注「简要」。批量补摘或全部重新摘要时显示进度条、当前阶段、每楼（合并时为每次请求）大致耗时和剩余时间；全部重新摘要显示为「正在全部重新摘要 X/Y」，继续时计入之前已完成的层数。「全部重新摘要」确认框：首段写明楼层范围、层数（其中还没有摘要的层数）和摘要请求次数；其下为「从第几楼开始」数字框，填写的楼层不是可以重新摘要的 AI 回复时，以警告色写明从哪一层开始；再下为替换与保留、旧总结作废与跳过的楼层、取消与继续三段说明，最后一行以警告色提醒先导出聊天备份；底部为「取消」和危险样式的「开始全部重新摘要」（没有可处理的楼层时停用）。有未完成的记录时，弹窗先显示已完成的层数、停下的楼层以及继续、重新开始各自的说明，底部为「取消」「重新开始…」「继续」，选「重新开始…」后转到上述说明。旧记忆兼容提示条中，只因总结引用了不存在的楼层而保护时有「清理残缺的总结…」，已有不同的旧格式备份时有「替换旧备份并转换…」，两者都先弹出确认框，要求先导出聊天。
- 规划讨论：从「创作规划」中的「规划讨论」卡片打开。手机上为从底部升起的面板，顶部留出状态栏，可点返回或下拉顶部的拖动条关闭；电脑上为居中窗口，可放大。标题栏有返回、放大和更多操作（复制全部讨论、删除最早的一轮、清空讨论），其下选择讨论参考的版本。消息按对话排列，说话人旁显示时间；模型回复中的标题、列表和粗体按格式显示，每条回复可复制。底部为讨论轮数、「生成草稿」和输入栏；等待回复时可停止。讨论满 12 轮或接近 48000 字时，底部提示条中有「删除最早的一轮」（满 12 轮时另有「清空讨论」），两者都弹窗确认。「生成草稿」从底部弹出面板，选择参考版本和阶段数量后确认，完成后可跳到草稿编辑器。
- 楼层面板：卡片头部显示楼号、时间和小标签（召回段数、不一致），右侧依次为展开箭头、番外键（点一下标为番外，再点一下取消）和单楼摘要键（没有摘要时生成，已有摘要时重新生成）；点击头部或按 Enter、空格展开，展开后头部不再重复摘要预览和时间。展开后依次为时间、地点（本楼没有记录地点时，以浅底、次要色显示最近一次记录的地点，点击可为本楼单独设置）、摘要正文（点击或用键盘进入编辑）、各类变动（按「图标 + 标题 + 细线」分组，含局势和生活档案）、没写入的内容（最后一次尝试中不合格而没有写入的更新，每项写明是哪一项和原因，左侧为警告色竖线）、记录冲突和召回记录，底部为「生成摘要 / 重新生成摘要」和「删除摘要」（在原位确认）。重新生成时，新结果先与现有摘要并排对比（摘要正文、时间和状态变化），选择「用新的」后才替换；手机上两份上下排列，选择按钮固定在底部。番外楼为虚线边框，番外键显示为按下，展开后顶部说明此楼不参与记忆，底部不显示按钮。正文与已有记录不一致时，头部标注「不一致」，面板中列出记录与正文原句，可选「提醒正文模型」或「忽略」。批量补摘时合并生成的摘要，面板中注明只有摘要和时间、未记录状态变动。由导入的旧总结覆盖的楼层，头部预览显示「已由导入的旧总结覆盖」，单楼摘要键不可用，展开后说明不单独摘要，底部不显示按钮；旧摘要未记录分页、当前不在第一页时同样处理，说明这一页不摘要、不注入，翻回第一页即恢复。插件停用或当前角色被排除时，楼层面板立即撤下，重新启用后立即补上。
- 札记卡片：启用双子札记时，显示在最新一条回复和有札记的楼层下方，头部、抽屉、分区标题和页脚与楼层面板相同；页脚右侧为「删除札记」，在原位确认，写明一起删除的安排数。
- 物品、场景、角色、变量：页头为一句说明，下方为统计行和各自的列表、搜索和编辑。角色页页头右侧为次要样式的「角色重新建档…」（刷新图标；没有有效摘要、记忆受保护或正在进行时停用）和主按钮「添加角色」；页面依次为主角、主要角色、NPC、生活小档案和信息差。进行中时统计行下方为进度卡片：左侧细强调色边，一行写旋转环、「角色重新建档」、当前步骤与进度（「第一步：补齐漏记 d/t 批」或「第二步：重做档案 d/t 个角色」）、当前批次（楼层范围或角色名）和「取消」（点后显示「停止中…」），下方一条细进度条。停下或做完时改为提示条：没有做完为警告色，写明进度、找到的新角色和档案改动数量、跳过的批次和停下的原因，按钮为「继续」「审核已找到的结果」「放弃」；做完为强调色，按钮为「审核」「放弃」；「放弃」先弹出确认框。开始前的确认框列出两步的请求次数，其下为警告色提示（费用较高、所用的 API、先导出聊天备份）和不改动的内容；有未完成的记录时按钮为「取消」「从头开始」「继续」。审核列表为宽版弹窗：首行写明新角色和档案改动的数量；没有做完时有一条警告色提示，有跳过的批次时另列一条；「新角色」「档案改动」两块各有标题、数量和「全选 / 全不选」，每项前为 18px 复选框（默认全选，整行可点）；新角色写名字、「首次登场 #N」、各字段和首次登场的原句，档案改动按角色分组，每个字段写「原」「新」两行和原句（左侧细竖线）；底部「关闭」和「应用所选（N 项）」固定在弹窗底部，没有勾选时停用；没有结果时显示一行说明和「完成」。主角、主要角色、NPC 三块各有二级标题和一句发送范围说明，NPC 一块的标题行右侧显示「显示 n / m 位」，其下为检索框和在场分组筛选（只作用于 NPC），再按在场、同区域、不在场分组。角色卡的操作键与名字同一行，字段标签为次要色，各档都显示外貌，改过名的角色显示「原记为」，无名角色在名字旁带「未具名」标签；位置以易读的方式显示，例如「跟主角在一起」「现在不确定；最后一次在旧街」；外貌、身份或性别为空时，卡片底部以虚线隔开，显示所缺项和「从原文补全」（小号次要按钮，检索中显示旋转环），确认弹窗列出可补字段及原文依据。开启「角色对主角的了解」或已有记录时，角色卡最下方以虚线隔开，显示折叠块「对〔主角名〕的了解」（默认收起，标题旁显示条数，右侧为展开键和添加键），展开后为发送范围说明和条目列表，每条可改写、删除；添加和改写使用弹窗，已有同一句时提示不重复添加；关闭该开关后已有条目照常显示，说明改为「注入设置中已关闭：不再记录，也不发送给正文模型」。没有主要角色或 NPC 时显示紧凑的空状态。生活小档案、信息差没有条目时缩成一行，展开后显示投放规则；信息差可结案、重开或删除。删除生活细节、信息差和物品前需要确认，确认框写明这项修改单独保存。注入设置中关闭了对应开关时，角色页各区块的发送说明改为「注入设置中已关闭，不发送给正文模型」。变量模板的结构编辑器中，字段改成已有的名字时不改名并提示，输入框恢复原名。场景页地点卡的操作在标题行右侧，窄屏时在卡片末尾。
- 札记：上方为启用开关和生成按钮，中间为札记和已确认的安排，独立 API 设置、自动生成与注入、整理版提示词（实际使用）、原版提示词、导入位于底部。每份札记展开后底部有「删除札记」，弹窗确认，写明一起删除的安排数和其中正在注入的条数。「已确认的安排」标题旁的标签显示「注入中 · N 条」（实际注入的条数）；有安排超出注入上限或依据的正文已改动时，标题下方显示警告条；依据的正文已改动的安排标「依据的正文已改动」，正文下方为警告条和「取消这条安排」，状态按钮不再停用。「自动生成与注入」中两项数字设置下方有一行说明各部分的上限。操作结果显示在对应按钮旁。
- 世界书：导航第 7 项，图标为地球（圆、赤道和一条经线），有待审核的建议时导航图标旁显示强调色角标。上方卡片为写入目标（下拉选择，选项标明聊天绑定、角色主世界书、角色附加、全局启用；其下显示所选书的标签、条目数和修改权限，当前聊天没有绑定世界书时提供「新建并绑定到当前聊天」）和生成区（下次读取的楼层范围、「生成建议」，生成中可取消）。中间为「待审核的建议」，按批列出，批次头部显示楼层范围、手动或自动、时间和写入的书，右侧为「全部忽略」「全部应用」（弹窗确认）；每条建议为一张卡片：动作标签（新建、追加、加关键词为强调色，替换、改写、提醒为警告色）、标题、uid、关键词，修改类建议以「改前 / 改后」两栏对比（手机上上下排列），删去的文字为红色删除线，新增的文字为强调色浅底加下划线，未改动的长段落只保留改动附近的文字，可展开全文；底部为依据楼层和理由、冲突或权限说明，以及「忽略」、编辑图标键和「应用」。依据楼层失效的批次为虚线边框，头部说明原因并提供「从第 N 楼重新读取」；批次的「全部应用」变为「仍然全部应用」，卡片的「应用」变为「仍然应用」，点击后先弹窗说明依据楼层已变。批次超过 20 批而删掉仍有效的待审核建议时，页面上方显示警告条说明删了哪一批。没有建议时显示空状态。再往下是「已写入记录」（折叠行，默认收起），每条显示动作、标题、uid、所在的书、时间和「撤销」，「查看改动」展开改前改后；撤销弹窗确认。底部为 API 设置、自动建议、修改权限（分段选择，每档附一行说明）、新条目默认值和读取范围（五项：楼层数、正文字数、相关条目全文、参考世界书、条目索引）。编辑建议、新建世界书使用弹窗。
- 设置：标题右侧显示版本号，悬停显示更新方式；其下为总开关和分组目录（插件在当前聊天停用——总开关关闭或角色被排除——且有棱镜宝书隐藏的楼层时，总开关下方显示提醒和「恢复显示这些楼层」按钮），其后为常用设置（副 API、札记与规划 API、基本设置、摘要设置）、记忆与召回（注入设置、向量记忆、召回调试）、提示词、高级过滤、数据与迁移。各卡片默认收起，点击标题展开；仅在自定义的时间标签提示词超出预算留给它的上限时，「注入设置」自动展开并显示警告。「札记与规划 API」显示札记、规划和世界书三项 API 是否已设置及所用模型，按钮切到对应页面并展开 API 设置。「摘要设置」中「启用自动摘要」之后为「回复结束后立即摘要」开关（自动摘要关闭时不可用，详细说明中写明重抽、续写和编辑后的处理），第一个数字项为「摘要字数」，其下的「字数档位」只影响总结和二次总结，说明中显示当前的总结（L1）字数；「失败重试次数」之后为「跟随主 API 时的最大回复」（数字项，跟随主 API 曾改用 8192 时其下显示提醒）和「跟随主 API 时发送预填充」开关，再后为「回看原文补全角色档案」开关。各数字框在失焦或回车后回到有效值。渠道弹窗的说明写明留空的温度、最大输出、超时在点「完成」后恢复默认值，以及开启流式传输时超时的计算方式。「自定义提示词」中，修改后内置版本又有更新的提示词标有「内置已更新」，打开可查看差异；「任务说明模式」之后为「内容边界」下拉（自动（按模型名）/ 始终发送 / 不发送，默认自动），说明写明自动时模型名含 deepseek 不发送，适用的任务等收在「详细说明」中；任务说明处于禁用时，编辑弹窗提示点「完成」只保存内容。「向量记忆 → 召回参数」中有关键词召回、在场角色加权和召回保留轮数；关闭向量记忆时，相关设置以浅底和次要色表示停用。「向量记忆 → 索引维护」有「补齐当前聊天索引」「清空并重建」「清空当前聊天索引」三个按钮，换了 Embedding 模型时上方显示提示；Rerank 端点内说明服务商不支持重排时清空模型；Query 重写端点的最大输出下方说明超时不重试、思考过程也计入输出上限。「召回调试」分五步逐行展开，行尾显示数量，顶部为与「召回」速览相同的结果说明（含没有重排、补建索引、换了 Embedding 模型的提示）；第 1 步在没有 INTENT 时注明重排改用全部检索语句；列出关键词命中；第 4 步标注每段来自哪一路，没有重排时标题为「分档（未重排）」，以「超出预算」「原文超出预算」标出受召回预算影响的段落，以「未达阈值」「超出条数」「已在历史摘要中」「关键词已收满」写明没有注入的原因，已在历史摘要中的段落另有标签。「注入设置」中有「信息差」开关，其后为「角色对主角的了解」（默认关闭，说明中写明本项同时控制记录）和「伤势进展提醒」开关，均附详细说明。「排除世界书内容」输入条目名规则时，输入框下方预览当前聊天使用的世界书中会命中的条目，命中较多时以提醒样式显示。模型下拉超过 200 个时，列表底部写明还有多少个、可输入关键词筛选。「数据与迁移」中有「设置备份」：导出设置（文件不含 API 密钥，文件名带日期）和导入设置；导入前确认框逐行列出会修改的设置、渠道增减、跳过的项，以及地址换了服务器、需要重新填写密钥的项。迁移和带数据新建对话的卡片在当前聊天处于只读保护或待转换时显示原因。

## 快捷回复栏

- 启用向量记忆时，输入框上方的快捷回复栏显示「召回」按钮，按钮上显示上次召回的段数（召回中、补索引中、未召回、召回失败时显示对应状态）。点击后弹出召回速览，显示每段的来源楼层、故事时间、注入的是全文还是摘要以及内容预览；「注入原文」为可折叠的一行。没有召回记录时显示说明。点击外部、按 Esc、点关闭键或再次点击按钮时收起；用 Esc 或关闭键收起后，焦点回到「召回」按钮。可在「设置 → 基本设置 → 在快捷回复栏显示召回」中关闭。

## 手机

- 导航可置于顶部或底部，名称均显示中文，共 8 项（列数随页面数变化，各项等宽）；320px 宽度下仍显示全部名称。可设置为再次点击当前页导航时关闭窗口。
- 窗口从底部弹出，可下滑关闭；窄屏和触屏上按钮、标签和滑块加大，便于点按。规划讨论在手机上从底部升起，顶部留出状态栏，可下拉关闭；「生成草稿」面板从底部弹出。
- 避开状态栏：宝书窗口和规划讨论顶部留出 4% 的高度；页面画到状态栏下面时（安全区不为 0），改为状态栏高度再加 8px，取两者中较大的。弹窗上下让出状态栏和底部手势条，再高也不超出这一范围，标题栏和关闭键始终在状态栏下方；悬浮球不会停在状态栏或手势条下面。
- 悬浮球：按下后移动不超过约 10px（触屏）或 6px（鼠标，按直线距离）算点按，点按时不挪动悬浮球，也不脱离贴边；系统手势打断时不算点按，拖到一半被打断时回到原位。自定义图标加载失败时显示默认的小狐狸，设置页预览同样处理并提示重新上传。
- 返回键：先关最上面一层（下拉列表和菜单、弹窗和确认框、规划讨论的草稿面板、规划讨论），最后关宝书窗口；全部关掉后恢复浏览器原来的行为。确认框处理中不会被返回键关掉。

## 键盘与读屏

- 弹窗打开时焦点位于弹窗内（有自动聚焦的输入框时停在输入框），Tab 在弹窗内循环，Esc 逐层关闭并将焦点返回原按钮。
- 电脑浏览器的后退键与手机返回键相同，逐层关闭。
- 收起的内容不会被 Tab 选中。楼层面板和札记卡片的头部可用 Enter、空格展开。
- 图标按钮带读屏名称；开关读作开关；下拉选择可用方向键移动、回车确认，Esc 只收起列表。

## 检查方式

界面在本地测试页面中检查：使用真实组件和虚构的演示数据，在 1280px、390px 和 320px 宽度及夜间、日间主题下截图核对，确认无横向溢出和页面报错；手机宽度下另模拟状态栏、底部手势条和软键盘弹出，逐个打开窗口、弹窗和菜单，确认退出键可点。返回键的逐层关闭在本地测试页面用 history.back() 模拟检查，未在安卓真机上验证。未在所有酒馆版本、手机真机和辅助技术上测试；「跟随 ST」主题的颜色由酒馆决定，不能保证所有主题下的对比度。
