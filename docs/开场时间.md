# 新聊天的统一开场时间

新聊天首次正常生成 / 自动整理开场白时，宝书会先准备一个当前聊天独立的时间起点，供正文和摘要共同使用。

- 已有明确的正文时间标签或用户设置时，优先沿用，不重新初始化。
- 没有时间依据时，使用统一虚构起点 **故事第1天 08:00**，不绑定现实日期或特定世界的公历年份。初始化仅一次，后续沿用并随明确剧情推进。
- 这个起点是后备设定；正文已写明的日期、深夜、黄昏、清晨等信息优先，不能被默认08:00覆盖。回忆中的年份不作为当前主线日期。
- 在摘要页的 **开场时间** 中可设置自己确认的开场时间。已经生成摘要的旧聊天不要改写整条时间线；需要修正时，编辑对应逐楼摘要的起止时间。

旧空标签与“时间待设定”等历史数据继续兼容，不会为了修标签自动重写聊天或重建 L1/L2。只有有效正文才会送去摘要；纯时间标签、思考块或札记旁注不会被当成剧情。

更新会识别上一版逐字保存的默认时间提示词，改用新默认；自己改写过的提示词保持不动。如果自定义提示词仍要求空时间，请在设置中自行调整或恢复默认。

时间标签仍由正文模型生成，提示词不能保证所有模型每次都遵守；代码负责共享初始化值与兼容旧空值，不会以“修复”为由给历史记录批量编造日期。
