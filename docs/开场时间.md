# 开场时间

新聊天第一次生成正文（或自动整理开场白）时，棱镜宝书会给这个聊天定一个时间起点，正文和摘要都从这里往后算。

- 正文里已经写了时间（时间标签），或者你在摘要页设置过开场时间，就用它。
- 都没有的话，从 **故事第1天 08:00** 开始。这是虚构的起点，不对应现实日期，也不套用某个世界的年份。只设定一次，之后随剧情往后推。
- 正文写明的日期，以及深夜、黄昏、清晨这类时段优先，不会被默认的 08:00 盖掉。回忆里出现的年份不算当前时间。

## 自己设置

摘要页底部的「开场时间」里，可以在还没有摘要、只有开场白的时候，填一个你想要的开场时间（可以是虚构的，不用写年份）。聊天开始后就不能再改了；要修正某一楼的时间，在摘要列表里编辑那一楼的起止时间，不需要重建。

## 旧聊天

以前的空时间标签、「时间待设定」等记录照常兼容。不会为了补时间自动改写聊天或重建 L1/L2，也不会给历史记录批量编造日期。只有有效的正文才会拿去摘要，单独的时间标签、思考内容和札记不会被当成剧情。

## 时间标签提示词

升级时会识别上一版原样保存的默认时间标签提示词，自动换成新的默认；自己改过的保持不动。如果你的自定义提示词还要求时间留空，请自己改掉，或者恢复默认。

时间标签由正文模型来写，提示词不能保证每个模型每次都照做。
