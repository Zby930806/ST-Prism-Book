# 开场时间

新聊天首次生成正文（或自动整理开场白）时，棱镜宝书为该聊天设定时间起点，正文和摘要的时间均由此推算。

- 正文中已有时间（时间标签），或已在摘要页设置开场时间时，使用该时间。
- 两者都没有时，从「故事第1天 08:00」开始。该起点为虚构时间，不对应现实日期，也不套用特定世界的年份。仅设定一次，之后随剧情推进。
- 正文写明的日期及深夜、黄昏、清晨等时段优先，不会被默认的 08:00 覆盖。回忆中出现的年份不作为当前时间。

## 手动设置

在摘要页底部的「开场时间」中，可在尚无摘要、只有开场白时填写开场时间（可为虚构时间，无需年份）。聊天开始后不能再修改开场时间；修正某一楼的时间时，在摘要列表中编辑该楼的起止时间，无需重建。

## 旧聊天

原有的空时间标签、「时间待设定」等记录保持兼容。不会为补全时间自动改写聊天或重建 L1/L2，也不会为历史记录批量生成虚构日期。只有有效正文参与摘要，单独的时间标签、思考内容和札记不作为剧情。只有这些内容、没有正文的楼层不请求 AI，会一直待摘要；可编辑正文，或在摘要页「未摘要楼层」中点击「标为番外」跳过。

已有摘要、但正文和摘要里都没有故事时间的旧聊天，摘要页底部显示「当前故事时间」，可设定截至最新一层摘要的时间。时间写进这层摘要的结束时间和状态时间（两处原本为空），之后的楼层从这个时间往后推算；更早楼层的补摘或重新摘要只看它们之前的楼层，不会拿到这个时间。不改正文、不改其他摘要、不重新摘要。不改开场时间的原因：之后的摘要先用最近一层的已知时间，没有才用开场时间，给旧聊天补开场时间会让模型以为现在仍是开场那一刻。最新几层还没摘要、或聊天完全没有摘要时，先补摘再设定。

## 时间标签提示词

升级时识别上一版原样保存的默认时间标签提示词，并自动替换为新的默认值；修改过的提示词保持不变。自定义提示词若仍要求时间留空，需手动修改或恢复默认。

时间标签由正文模型生成，提示词不能保证每个模型每次都遵守。
