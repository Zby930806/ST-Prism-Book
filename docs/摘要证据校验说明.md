# 摘要报错：伤势和位置的证据

## 报错原因

记录伤势和身体状态时，摘要使用「局部更新」（conditionPatch）：只修改有新依据的部分，保留旧伤和行动限制。每一项都需填写状态文字，并附本楼正文中的原话作为证据；替换旧的某一段时，还需填写该段编号。角色位置变化也需附原话。

模型给出的原话在正文中找不到、字段缺失、类型错误、编号错误或补丁位置错误时，该楼摘要不保存。页面会说明出错的人物和项目序号。

## 原话的核对方式

- 只在该楼清理后的原文中查找。发给模型的请求文本（带来源编号和说明）不作为原文，多条消息拼接也不作为证据。
- 允许成对的 Markdown 强调符号、中文排版中的空格和换行；改字、改标点、删除否定词、拼接均不通过。
- 失败后按设置中的「失败重试次数」重试，不会无限重试。

## 失败后的处理

- 失败的楼层保留原有摘要和状态，不被覆盖。批量补摘在失败的楼层停止，以免后续楼层使用错误的前序状态。
- 没有摘要的楼层：点击摘要页上方的「补摘」，或在「未摘要楼层」中点击楼层号单独补摘。已有摘要需要重做时：在「设置 → 基本设置」中启用楼层面板，在该楼点击重新生成；新结果先与现有摘要并排对比，选择「用新的」后才替换。无需重建整个聊天，也无需重新生成旧的 L1/L2。
- 仅在修改了早期剧情、需要从该处重新推算后续状态时，才需要重建。

该检查只能证明原话出自正文，不能证明原话支持对应的伤势变化。部分模型仍可能报错。
