# 棱镜宝书 · Prism Book

SillyTavern 的长期记忆扩展。基于柏柏的 [ST-BaiBai-Book](https://github.com/baibai-git/ST-BaiBai-Book) 修改，由维护者公开分发，不是原作者的官方版本。原作信息和授权范围见 [NOTICE.md](NOTICE.md)，每个版本的改动见 [CHANGELOG.md](CHANGELOG.md)。

截图取自本地测试页面，使用虚构的演示数据。

## 功能

- 摘要：每层楼生成摘要，摘要达到一定数量时进一步总结（L1、L2……）。生成正文时，较早的剧情以摘要代替原文注入，节省上下文。
- 状态：生成摘要时同时记录时间地点、物品、场景、角色、计划和悬念、信息差、自定义变量，各有独立页面，均可手动修改。
- 双子札记：模型在故事外就后续剧情提出问题，经确认的方案作为「安排」。使用独立的 API，默认关闭。见 [双子札记说明](docs/双子札记.md)。
- 创作规划：位于摘要页「当前局势与计划」，根据剧情和用户要求生成分阶段规划，确认后只将当前阶段注入正文。见 [创作规划说明](docs/大纲规划.md)。
- 向量记忆（可选）：从旧剧情中检索与当前剧情相关的片段，注入正文。

## 1.2.9-prism.14 的改动

- 批量补摘新增「较早楼层合并摘要」（待补摘达到 30 层时可选）：最近若干层逐层摘要并记录状态，更早的楼层每次合并若干层请求一次，只写每层的摘要和时间，请求次数大幅减少。合并生成的摘要照常合并为总结，也可被向量召回。
- 自动合并总结改为按楼层先后排序；在已有摘要之前补摘较早楼层时，上层总结不再前后颠倒。

prism.13 新增快捷回复栏「召回」按钮、楼层面板召回记录、关键词召回与在场角色加权、规划推进条件检查、记录冲突和信息差；prism.11 新增重新摘要对比、补摘剩余时间和自定义提示词过期提醒，设置页卡片默认收起。详见 [CHANGELOG](CHANGELOG.md)。

## 升级

旧聊天无需重建。原有的逐楼摘要、L1/L2 总结和状态继续使用；无法识别的格式进入只读保护，不覆盖原数据。详见 [旧记忆接续说明](docs/LEGACY-COMPATIBILITY.md)。

摘要页底部保留「重建记忆」。该操作会重新请求 AI 并替换现有摘要，仅用于从头重做，升级时不需要。

## 安装与更新

在酒馆扩展面板中点击「安装扩展」，填入本仓库地址。更新在酒馆的「管理扩展」中进行，插件不自动检查更新。

从柏宝书迁移时：

1. 备份酒馆数据、设置和旧插件目录。
2. 停用柏宝书，并将其文件夹移出 extensions 目录（仅改名无效）。两个版本共用同一份数据，不能同时启用。
3. 安装本扩展，强制刷新页面。
4. 打开旧聊天的摘要页，检查兼容状态。先在聊天副本上测试，确认无误后再用于正式聊天。

手动安装：将完整的 ST-Prism-Book 文件夹放入酒馆用户目录下的 extensions 文件夹，确认第一层包含 manifest.json，且存在 dist/index.js 和 dist/index.css。

最低支持的酒馆版本与原插件相同：SillyTavern 1.12.13。未在所有酒馆版本上实测。

## 提示词

内置提示词可在「设置 → 提示词」中修改或恢复默认。导出副本见 [docs/prompts](docs/prompts/00-说明.md)。

## 开发

依赖版本由 pnpm-lock.yaml 锁定：

~~~sh
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm build
pnpm export:prompts
pnpm release:check
~~~

仓库同时包含源码和构建后的 dist，可直接安装。修改源码后需重新构建，并将 dist 和 manifest 一同提交。发布前参阅 [发布说明](docs/INTERNAL-RELEASE.md)。

## 其他

- 功能问答见 [FAQ](FAQ.md)（来自原项目，安装和更新方式以本说明为准）；报错含义和处理方法见 [常见报错](docs/常见报错.md)；供其他插件使用的接口见 [PUBLIC_API.md](PUBLIC_API.md)；界面说明见 [UI-DESIGN.md](docs/UI-DESIGN.md)。
- 为兼容旧数据，数据键、宏、事件和接口沿用原名（如 baibai_book、bbs_*）。
- 界面中的「内部版」是本维护分支的版本标识，与仓库是否公开无关。package.json 中的 private: true 仅用于防止误发布到 npm。
- 标题栏和默认悬浮球使用 PrismFox 的小狐狸图标（图片内嵌在插件中，无需单独的图片文件），见 [品牌说明](docs/LOGO-BRIEF.md)。
- 模型仍可能出错。自动测试只检查程序行为，不保证各模型、预设和剧情下的生成质量。
