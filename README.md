# 棱镜宝书 · Prism Book

SillyTavern 的长期记忆扩展。基于柏柏的 [ST-BaiBai-Book](https://github.com/baibai-git/ST-BaiBai-Book) 修改，由维护者公开分发，不是原作者的官方版本。原作信息和授权范围见 [NOTICE.md](NOTICE.md)，每个版本的改动见 [CHANGELOG.md](CHANGELOG.md)。

## 它做什么

- **摘要**：每层楼写成一条摘要，攒够了合并成总结（L1、L2……）。生成正文时，较早的剧情用摘要代替原文发给模型，省上下文。
- **状态**：顺带记下时间地点、物品、场景、角色、计划和悬念、自定义变量，各有一页，都能手动修改。
- **双子札记**：模型在故事外提几个问题和你商量后面怎么写，你确认过的方案才算「安排」。用单独的 API，默认关闭。见 [双子札记说明](docs/双子札记.md)。
- **创作规划**：在摘要页的「当前局势与计划」里，按剧情和你的想法生成分阶段的规划，确认后一次只把当前阶段交给正文模型。见 [创作规划说明](docs/大纲规划.md)。
- **向量记忆**（可选）：从旧剧情里找回和当前相关的片段，补给正文模型。

## 1.2.9-prism.8 的改动

- 报错写清楚了。回复被截断（输出达到长度上限）、密钥无效、额度不足、限流、地址或模型名不对、上下文超长、内容审核、连不上服务器、超时等，都会直接说是哪种问题、去哪个设置里改。服务商的原话放在可展开的「技术细节」里，密钥和带参数的地址会被遮住。见 [常见报错](docs/常见报错.md)。
- 札记写到一半被截断时，已写出的部分会保存并标明不完整，不再整份丢掉。
- 札记的默认最大输出从 3000 调到 8000（可设到 65535）。以前保存的还是旧默认值 3000 的，会自动按 8000 用；自己改过的不变。
- 界面文字改成平常的说法，去掉了各页的标语。札记页、设置页和创作规划区重新排版，开关统一成拨动开关。
- 换上了小狐狸标志；按钮、输入框和几处面板的细节更精致。摘要页上方有常驻的「补摘」按钮，有漏摘的楼层时会显示层数。

## 升级

旧聊天不需要重建。旧的逐楼摘要、L1/L2 总结和状态都直接沿用；格式认不出来时进入只读保护，不会覆盖原数据。详见 [旧记忆接续说明](docs/LEGACY-COMPATIBILITY.md)。

摘要页底部的「重建记忆」仍然保留。它会重新请求 AI、替换现有的摘要，只在你确实想从头重做时用，升级用不到它。

## 安装与更新

在酒馆的扩展面板点「安装扩展」，粘贴本仓库地址即可。更新也在酒馆的「管理扩展」里操作，插件自己不检查更新。

从柏宝书换过来时：

1. 备份酒馆数据、设置和旧插件目录。
2. 停用旧的柏宝书，并把它的文件夹移到 extensions 目录外面（只改名不够）。两个版本不能同时启用，它们共用同一份数据。
3. 安装本扩展，强制刷新页面。
4. 打开一个旧聊天的摘要页，看看兼容状态。先在聊天副本上试，没问题再用到正式聊天。

也可以手动安装：把完整的 ST-Prism-Book 文件夹放进酒馆用户目录下的 extensions 文件夹，确认第一层就有 manifest.json，并且有 dist/index.js 和 dist/index.css。

最低支持的酒馆版本沿用原插件：SillyTavern 1.12.13。没有在所有酒馆版本上实测过。

## 提示词

内置提示词可以在「设置 → 提示词」里修改或恢复默认。导出的副本在 [docs/prompts](docs/prompts/00-说明.md)。

## 开发

依赖版本由 pnpm-lock.yaml 锁定：

~~~sh
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm build
pnpm export:prompts
pnpm release:check
~~~

仓库同时提交源码和构建好的 dist，方便直接安装。改了源码就要重新构建，把 dist 和 manifest 一起提交。发布前看一下 [发布说明](docs/INTERNAL-RELEASE.md)。

## 其他

- 功能问答见 [FAQ](FAQ.md)（来自原项目，安装和更新方式以本说明为准）；给其他插件用的接口见 [PUBLIC_API.md](PUBLIC_API.md)；界面说明见 [UI-DESIGN.md](docs/UI-DESIGN.md)。
- 为了让旧数据直接接上，数据键、宏、事件和接口都沿用原名（如 baibai_book、bbs_*）。
- 界面里的「内部版」是这个维护分支的版本标识，和仓库是否公开无关。package.json 里的 private: true 只是防止误发布到 npm。
- 标题栏和默认悬浮球用小狐狸标志（内联 SVG，不需要图片文件），见 [品牌说明](docs/LOGO-BRIEF.md)。
- 模型还是会出错。自动测试检查的是程序行为，不能保证每个模型、预设和剧情下的生成质量。
